GarageLog OCR Setup for Windows

GarageLog can index normal text-based PDF, DOCX, and text files without extra software.
Scanned PDFs and image files require two local tools:

1. Tesseract OCR — reads text from images.
2. Poppler — converts scanned PDF pages into images for OCR.

Recommended setup:
1. Download install-garagelog-ocr-tools.ps1 from the OCR status window.
2. Right-click the downloaded file and choose Run with PowerShell.
3. Approve the installation prompts. The script uses winget.
4. Close and restart GarageLog.
5. Open Documents > OCR & Indexing Status and select Index All.

All document processing remains local.
