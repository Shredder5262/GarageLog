# Privacy

GarageLog is local-first. It does not include advertising, analytics, usage telemetry, cloud synchronization, GPS tracking, or an external account service.

The optional update checker requests public release metadata from GitHub when `GARAGELOG_UPDATE_REPOSITORY` is configured. The request contains the GarageLog version in its user-agent and does not include user records, vehicle data, documents, filenames, profile information, or authentication data.

Anonymous document-share links are created only through an explicit Share Document action. Anyone who possesses an active share link can access that individual file, so revoke links that are no longer needed and avoid publishing them publicly.
